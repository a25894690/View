# 影片字幕編輯器

在瀏覽器裡直接編輯影片字幕的小工具，不需要安裝、不會上傳檔案（全部在本機處理）。

```
┌──────────────────────────────┬──────────────────┐
│                              │ 指定時間改字幕   │
│        影片（可直接點字幕編輯）│  開始 / 結束 / 文字│
│                              ├──────────────────┤
├──────────────────────────────┤ 字幕列表         │
│ ▶ 00:12.300  ＋新增  ✂分割   │  #1 00:02 → 00:04│
├──────────────────────────────┤  #2 ...          │
│ 時間尺 / 字幕軌 / 音軌波形     ├──────────────────┤
└──────────────────────────────┴ 字幕樣式         ┘
```

## 使用方式

直接用瀏覽器開啟 `index.html` 即可；或在資料夾裡啟動一個本機伺服器：

```bash
python3 -m http.server 8000
# 然後打開 http://localhost:8000
```

1. 點「開啟影片」或把影片拖進左邊播放區。
2. 加字幕的幾種方法：
   - **右上「指定時間改字幕」**：輸入時間（如 `1:23.5`、`83.5`、`1分23秒`）和文字按「套用」。
     該時間已經有字幕 → 改成新文字；沒有 → 新增一條（結束時間留空預設 2 秒）。
   - **直接點影片上的字幕**修改，Enter 完成、Shift+Enter 換行；沒有字幕的地方點提示框就會新增。
   - 按「＋ 新增字幕」或鍵盤 `N`，在目前播放位置新增。
   - 在時間軸的字幕軌**雙擊空白處**新增。
3. 時間軸：拖曳字幕方塊移動、拖曳左右邊緣調整長短（會自動吸附到播放頭和其他字幕邊緣），滾輪捲動、Ctrl+滾輪縮放。
4. 匯出：
   - **匯出 SRT / VTT**：字幕檔，可搭配 YouTube、剪映、Premiere 等使用。
   - **輸出含字幕影片**：把字幕燒進畫面，產生新的影片檔（Chrome/Edge 會輸出 WebM 或 MP4，依瀏覽器支援而定）。輸出時影片會以正常速度播放一遍。
5. 也可以匯入現有的 `.srt` / `.vtt` 繼續修改。字幕會自動存在瀏覽器裡，重新整理不會不見。

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| 空白鍵 | 播放 / 暫停 |
| ← / → | 後退 / 前進 1 秒（Shift：5 秒） |
| , / . | 上一格 / 下一格畫面 |
| N | 在目前時間新增字幕 |
| S | 在目前時間分割字幕 |
| [ / ] | 把選取字幕的開始 / 結束設為目前時間 |
| Delete | 刪除選取的字幕 |
| Ctrl+Z / Ctrl+Shift+Z | 復原 / 重做 |

## 檔案

- `index.html` – 版面
- `style.css` – 樣式
- `app.js` – 所有功能（播放、時間軸、音軌波形、字幕編輯、匯入匯出、燒錄輸出）
