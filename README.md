# 影片字幕編輯器

在瀏覽器裡直接編輯影片字幕的小工具，不需要安裝、不會上傳檔案（全部在本機處理）。

```
┌──────────────────────────────┬──────────────────┐
│                              │ 指定時間改字幕   │
│        影片（可直接點字幕編輯）│  開始 / 結束 / 文字│
│                              ├──────────────────┤
├──────────────────────────────┤ 字幕列表         │
│ ▶ 00:12.300  ＋新增  ✂分割   │  #1 00:02 → 00:04│
├──────────────────────────────┤  #2 ...          │
│ 時間尺 / 字幕軌 / 音軌波形     ├──────────────────┤
└──────────────────────────────┴ 字幕樣式         ┘
```

## 使用方式

直接用瀏覽器開啟 `index.html`，或用網址 https://a25894690.github.io/View/ 。

1. 點「開啟影片」或把影片拖進左邊播放區。
2. 右邊有三個分頁：

### 字幕
- **指定時間改字幕**：輸入時間（如 `1:23.5`、`83.5`、`1分23秒`）和文字按「套用」。該時間已有字幕 → 改成新文字；沒有 → 新增。
- **直接點影片上的字幕**修改，Enter 完成、Shift+Enter 換行；沒有字幕的地方點提示框就會新增。
- **字幕校對**：改過的句子會變橘色，下面留原文對照，標題顯示「N 句已改」。
  - 游標放在句子中間按 `Ctrl/⌘ + Enter` → 拆成兩句，時間依字數自動切開。
  - 在句首按 `Backspace` → 併回上一句。

### 審片留言
1. 暫停在要改的畫面，在留言框打修改意見。一開始打字，時間就會鎖定，影片跑掉也不影響。
2. 想在畫面上圈東西：按「✏ 畫記」，選顏色直接在影片上畫，畫完按「✓ 畫完了」。
3. 按「＋ 加入留言」，留言連同當下畫面（含畫記）的縮圖會進到「修改清單」。
4. 全部標完後：
   - **匯出審片意見 (.md)**：存成檔案，縮圖會一起存進去。
   - **複製文字**：直接複製，貼到 Claude Code 跟他說「照審片意見改」。
   內容包含：修改清單、刪除片段、字幕修改（原文 → 新文字）。

### 刪除片段
1. 在下方**音軌波形上拖曳框選**沒講話或不要的段落，可以先按「▶ 試聽選取」（`P`）聽一下。
2. 按 `X` 標記刪除，會變紅色並列在「刪除片段」分頁，顯示「原長 → 剪後」的長度。
3. 每段可以用 ‹ › 微調開始 / 結束（0.1 秒），▶ 試聽剪掉後的效果，✕ 取消。
4. 勾選「播放時跳過刪除片段」即可預覽剪後的節奏。

### 時間軸
拖曳字幕方塊移動、拖曳左右邊緣調整長短（會自動吸附到播放頭和其他字幕邊緣），雙擊字幕軌空白處新增；滾輪捲動、Ctrl+滾輪縮放。綠色小三角是留言位置，紅色是刪除片段。

### 匯出
- **匯出 SRT / VTT**：字幕檔。有刪除片段時會詢問要不要把時間對齊剪後的影片。
- **輸出含字幕影片**：把字幕燒進畫面並**自動剪掉刪除片段**，產生新的影片檔（依瀏覽器支援輸出 MP4 或 WebM）。輸出時影片會以正常速度播放一遍。

字幕、刪除片段、留言都會自動存在瀏覽器裡，重新整理不會不見（換電腦請先匯出 SRT）。

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| 空白鍵 | 播放 / 暫停 |
| ← / → | 後退 / 前進 1 秒（Shift：5 秒） |
| , / . | 上一格 / 下一格畫面 |
| N | 在目前時間新增字幕 |
| S | 在目前時間分割字幕 |
| [ / ] | 把選取字幕的開始 / 結束設為目前時間 |
| X | 把音軌上框選的範圍標記刪除 |
| P | 試聽選取範圍 / 刪除片段 |
| D | 開關畫記模式 |
| Delete | 刪除選取的字幕或刪除片段 |
| Esc | 取消選取 / 離開畫記 |
| Ctrl+Z / Ctrl+Shift+Z | 復原 / 重做 |

## 檔案

- `index.html` – 版面
- `style.css` – 樣式
- `app.js` – 所有功能（播放、時間軸、音軌波形、字幕校對、審片留言與畫記、刪除片段、匯入匯出、燒錄輸出）
