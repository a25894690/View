# 影片編輯程式

使用者說「影片編輯程式」時，指的就是這個專案。使用者用繁體中文溝通，常用手機，不是工程師：回答要用白話，步驟要具體，不要丟一堆術語。

## 功能總覽（版面：左上影片、左下時間軸、右側三個分頁）

- **影片區**：直接點影片上的字幕修改（Enter 完成、Shift+Enter 換行），沒字幕處點提示框新增；暫停時字幕左邊有黃色 ✥ 可拖曳改位置；✏ 畫記模式可在畫面上圈東西。
- **時間軸**：時間尺 / 字幕軌 / 音軌波形。拖曳字幕方塊移動、拖邊緣調長短（會吸附）、雙擊空白新增；在音軌上拖曳是框選範圍，按 X 標記刪除；滾輪捲動、Ctrl+滾輪縮放。綠色小三角 = 留言，紅色 = 刪除片段。
- **右側「字幕」分頁**：
  - 指定時間改字幕：輸入時間（`1:23.5`、`83.5`、`00:01:23,500`、`1分23秒` 都可以）+ 文字 → 該時間有字幕就改，沒有就新增。
  - **字幕校正**（名稱是使用者指定的，不要改回「校對」）：改過的句子變橘色並保留原文、顯示「N 句已改」；Ctrl/⌘+Enter 從游標處拆句（時間依字數比例切），句首 Backspace 併回上一句。
  - 🎨 部分文字變色：選取字再點顏色。
  - 🎯 單句位置 / 大小：滑桿或在影片上拖 ✥。
  - 字幕樣式（全域）：大小、離底、顏色、背景、描邊、粗體。
- **右側「審片留言」分頁**：打字時時間自動鎖定；可附畫記；加入後連同縮圖進「修改清單」；「匯出審片意見 (.md)」（含圖）或「複製文字」貼給 Claude Code，內容含修改清單、刪除片段、字幕修改、字幕樣式調整。
- **右側「刪除片段」分頁**：列出框選刪除的段落、可 ‹ › 微調 0.1 秒、試聽、顯示「原長 → 剪後」；可勾選播放時跳過。
- **匯出**：SRT（含 `<font color>`）、VTT（純文字）；有刪除片段時會問要不要對齊剪後時間。「輸出含字幕影片」用 canvas + MediaRecorder 即時錄製，會燒入字幕、套用顏色位置、跳過刪除片段，輸出 MP4 或 WebM（看瀏覽器）。
- 其他：倍速、復原 / 重做、快捷鍵、資料自動存在瀏覽器 localStorage（換電腦要先匯出 SRT）。

快捷鍵：空白 播放、←/→ 1 秒（Shift 5 秒）、, . 逐格、N 新增、S 分割、X 標記刪除、P 試聽、D 畫記、[ ] 設開始 / 結束、Delete 刪除、Esc 取消、Ctrl+Z / Ctrl+Shift+Z。

## 修改程式的流程

1. **取得程式碼**：如果工作目錄裡沒有這個 repo，先用 `add_repo`（owner `a25894690`、repo `View`、access `push`）加入，再 clone 並切到 `claude/keen-davinci-gk26cu`。如果 session 指定了別的開發分支，先問使用者要推到哪裡，因為網站只會從上面那個分支部署。
2. **先讀相關程式**：程式結構和重要函式見 `references/code-map.md`，改之前先讀一下，避免破壞既有功能（例如復原、存檔、輸出影片）。
3. **修改時遵守的慣例**：
   - 介面文字一律繁體中文，用詞照現有的（例如「字幕校正」）。
   - 改字幕或刪除片段前呼叫 `pushUndo()`，改完呼叫 `changed()`，這樣復原、存檔、列表、時間軸才會一起更新。
   - 改字幕文字要用 `setText(s, text)`，它會保留原文並讓變色範圍跟著位移。
   - 新增要保存的欄位時，同步更新 `load()`、`save()`；影響畫面的，也要同步更新 `drawSubtitle()`（輸出影片）和 `placeOverlay()` / `updateOverlay()`（影片預覽），兩邊外觀要一致。
   - 不引入建置工具或外部套件，維持「打開 index.html 就能用」。
4. **實際測試**：用 `node --check app.js` 檢查語法，再用 Playwright 開頁面跑一遍。測試影片用 ffmpeg 產生，例如：
   ```bash
   ffmpeg -f lavfi -i testsrc=size=1280x720:rate=30 \
     -f lavfi -i "aevalsrc='if(lt(mod(t\,3)\,2)\,sin(440*2*PI*t)\,0)':s=44100" \
     -t 12 -c:v libvpx -b:v 1M -c:a libopus test.webm
   python3 -m http.server 8765   # 在 repo 目錄
   ```
   頁面上 `window.__editor` 提供 `state`、`toSRT`、`reviewText`、`cutStats` 等方便檢查。新瀏覽器的 localStorage 是空的，測字幕相關功能前要先匯入 SRT 或新增字幕。截圖確認版面沒有被擠壞（右側欄寬 400px，按鈕多時容易溢出）。
5. **更新說明**：功能有變時同步更新 `README.md` 和 `index.html` 裡的「快捷鍵」說明視窗。
6. **commit 並 push** 到 `claude/keen-davinci-gk26cu`，然後告訴使用者：改了什麼、怎麼用、幾分鐘後打開網址按 Ctrl+F5。

## 回答使用者的常見問題

- **網址在哪 / 怎麼打開**：https://a25894690.github.io/View/ ，建議用電腦的 Chrome 或 Edge；手機能開，但時間軸拖曳和快捷鍵不好用。
- **打開還是舊版**：等 2～3 分鐘，按 Ctrl+F5；或到 https://github.com/a25894690/View/actions 看是否為綠色勾勾。
- **出現 404**：Pages 可能還在建置，或 Pages 設定的分支被改掉了，請使用者到 https://github.com/a25894690/View/settings/pages 確認。
- **字幕不見了**：資料存在那台電腦的瀏覽器裡，換電腦、清除瀏覽資料或用無痕模式都會看不到；請使用者養成匯出 SRT 的習慣。
- **輸出的影片格式**：看瀏覽器，Chrome 新版通常是 MP4，其他可能是 WebM；輸出時影片會以正常速度播一遍，要等跟影片一樣長的時間，分頁要保持在前景。
